CSS Task 4 – Box Model


Introduction

The CSS Box Model describes how elements are displayed on a webpage. Every HTML element consists of Content, Padding, Border and Margin.


1. Padding

Padding is the space between the content and the border. - 10px: Less inner space. - 25px: Medium inner space. - 40px: More inner space.

2. Border

Border is the line surrounding the content and padding. - 2px: Thin border. - 6px: Medium border. - 10px: Thick border.

3. Content Width

Width controls the horizontal size of an element. - 150px: Small width. - 300px: Medium width. - 450px: Large width.

4. Height

Height controls the vertical size of an element. - 50px: Small height. - 100px: Medium height. - 150px: Large height.

5. Box Sizing

Content-box: Width and height apply to the content only. Padding and border are added outside. Border-box: Width and height include content, padding and border.

Conclusion

In this assignment, I learned how Padding, Border, Width and Height affect the CSS Box Model. I also learned the difference between Content-box and Border-box.
